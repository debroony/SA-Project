1. หน้าสมัครสมาชิก (register.html): เขียน Go API สำหรับรับข้อมูลผู้ใช้ แล้วใช้ JavaScript (fetch) ส่งข้อมูลแบบ POST ไปบันทึกลงตาราง CUSTOMER

2. หน้าเข้าสู่ระบบ (login.html): เขียน Go API คอยเช็ค Username และ Password ที่ลูกค้ากรอกเข้ามาว่าตรงกับข้อมูลในตาราง CUSTOMER หรือ EMPLOYEE ใน SQL หรือไม่

3. หน้าสั่งซื้อสินค้า (order.html): เชื่อมต่อกับฟังก์ชันเช็คโควต้า 999 ชิ้นที่เราเขียนไว้ใน order_service.go และบันทึกลงตาราง ORDERS กับ ORDER_PRODUCT

4. หน้าชำระเงิน (payment.html): อัปโหลดไฟล์สลิปเก็บลงเซิร์ฟเวอร์และบันทึกชื่อไฟล์ลงตาราง PAYMENT พร้อมเปลี่ยนสถานะออเดอร์ใน SQL

5. หน้าหลังบ้านแอดมิน (admin_dashboard.html): ดึงข้อมูลรายการออเดอร์ทั้งหมดจาก SQL มาแสดงผลแบบ Real-time และทำปุ่มกดอัปเดตสถานะออเดอร์
