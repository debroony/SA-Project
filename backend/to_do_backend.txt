1. ระบบคำนวณโควต้าและสั่งซื้อ (ไฮไลท์สำคัญของโปรเจกต์)

    ฟังก์ชันเช็คโควต้า 999 ชิ้น: เขียนโค้ด SQL (SELECT SUM) เพื่อรวมยอดขนมจากตาราง ORDER_PRODUCT เฉพาะวันที่ลูกค้าเลือก หากยอดรวมบวกกับออเดอร์ใหม่แล้วเกิน 999 ชิ้น ระบบต้องปฏิเสธการสั่งซื้อ

    ฟังก์ชันสร้างใบสั่งซื้อ: หากโควต้าไม่เต็ม ให้ระบบรับข้อมูลจากหน้า order.html มาบันทึกลงตาราง ORDERS (สร้างเลขออเดอร์) และ ORDER_PRODUCT (รายการขนมที่สั่ง)

2. ระบบอัปโหลดสลิปและยืนยันการชำระเงิน

    ฟังก์ชันรับไฟล์รูปภาพ: เขียน API รับไฟล์สลิปโอนเงินจากหน้า payment.html มาเก็บไว้ในโฟลเดอร์ของเซิร์ฟเวอร์

    ฟังก์ชันบันทึกการชำระเงิน: นำชื่อไฟล์รูปไปบันทึกลงตาราง PAYMENT และสั่งอัปเดตคอลัมน์ Status ในตาราง ORDERS ให้เปลี่ยนเป็น "รอตรวจสอบ"

3. ระบบหลังบ้านสำหรับเจ้าของร้าน (Admin Dashboard)

    ฟังก์ชันดึงสรุปยอดรายวัน: ดึงข้อมูลจากตาราง ORDERS ไปแสดงผลบนหน้า admin_dashboard.html เพื่อให้ร้านเห็นออเดอร์ทั้งหมด

    ฟังก์ชันอัปเดตสถานะ: ทำ API สำหรับรับค่าจากปุ่ม Dropdown บนหน้าเว็บ เพื่อแก้สถานะใน Database (เช่น จาก "รอตรวจสอบ" -> "กำลังผลิต" -> "พร้อมส่ง")

4. ระบบจัดการผู้ใช้งาน (User Management)

    ฟังก์ชันสมัครสมาชิก: รับข้อมูลจากหน้า register.html มาบันทึกลงตาราง CUSTOMER

    ฟังก์ชันเข้าสู่ระบบ: นำ Username และ Password ที่กรอกในหน้า login.html ไปเช็คเทียบกับข้อมูลใน Database ว่าตรงกันหรือไม่

ทั้งหมดนี้เราจะเขียนโค้ดภาษา Go ลงในไฟล์ main.go และใช้เทคนิคสร้าง API ให้หน้าเว็บส่งข้อมูลเข้ามาหาครับ
